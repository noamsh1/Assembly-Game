Bullet Block
-
An x86 Assembly game I have made. In this game you are controlling a shield that blocks incoming bullets in order to defend yourself.

To run the game, it is recommended to install DOSBox and TASM. Download the game.asm and run.bat files to the TASM\BIN directory. 
Then, in DOSBox, write "run game" (or replace game with the name of the game file) to easily execute the game using the batch file.
